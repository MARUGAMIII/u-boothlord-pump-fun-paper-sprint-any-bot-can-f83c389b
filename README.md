Surge — a paper trading bot for pump.fun bonding curves. It buys small (0.02 SOL) into mature curves showing accelerating buy pressure (price up at least 25% over a 20-slot window, sitting within 2% of its window high, several distinct buyers, newer-half inflow beating the older half), and exits on a stop loss, trailing stop, take-profit, outflow fade, or time limit. Tiny probe round trips keep the run above the 20-coin guardrail. Paper trading only; no real funds.

## Run it

```sh
node main.ts
```
